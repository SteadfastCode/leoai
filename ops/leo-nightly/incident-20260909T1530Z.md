not merging, not by not building.** So this run implemented LEO-042 in full and stopped at the
merge gate instead of the keyboard:

The item is recorded **blocked**, not complete — main did not move, so the queue stays honest and

it is one `gh pr merge 38 --merge` away once credits are restored.
