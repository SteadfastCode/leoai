The backend's Anthropic API account has run out of prepaid credits. Every chat
request fails at the Claude call, regardless of entity or code version.

## Why this was NOT auto-reverted

STEP 15 says revert on smoke failure — but the premise of a revert is that the
merged change broke production. That premise is provably false here:

- LEO-041's diff touches only `services/analytics.js`, an analytics route in
  `dashboard.js`, tests, and dashboard Vue files. The chat path is untouched.
- The baseline smoke passed at 00:39Z and LEO-039's post-deploy chat check
  passed at ~00:48Z (216-char reply) — credits ran out between then and 01:04Z.
- Every other smoke check passes on the new deploy: health commit matches
  merge sha a126233 with mongo 1, dashboard + hashed asset 200, admin search
  top score 0.7912 (≥ 0.75), widget byte-length + syntax OK, CORS header
  present even on the failing /chat response.
- The failing dependency is external and code-independent: a revert would
  redeploy older code against the same empty credit balance, the post-revert
  smoke would fail identically, and STEP 15 would then force a permanent stop.

This is the same failure class the STEP 9 baseline exists to catch (external
outage masquerading as a bad deploy) — it happened to land after the merge
instead of before it.

## Impact

- Production chat (all entities) is down until credits are topped up.
- Query classification (Haiku) and topic summarization also use the same API
  account and will fail the same way.
- Scrapes/embeddings (Voyage) and the dashboard are unaffected.
